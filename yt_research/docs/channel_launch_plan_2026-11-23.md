## 1. 重点3ジャンルの実測比較(保存DB、直近90日・音楽除外)

集計はジャンル別の検索テーマから動画を割り当てたもの(Bは「restor/修復/復元」等のタイトル語も追加)。再生数順で集めたヒットと、日付順で集めた母集団(日付サンプル)は分けて表示。スクリプト: 作業中の `/tmp` 集計(再現可能な形で今後 `ytr` に移す)。

| 項目 | A 短編ドラマ・ホラー | B 修復・再生(タイトル語で抽出) | C 科学・技術 |
|---|---|---|---|
| 90日内の動画 / チャンネル | 337 / 222 | 1,640 / 269 | 594 / 455 |
| 5万再生以上の動画 / チャンネル | 321 / 206 | 652 / 153(厳密な修復語のみ: 372 / 64) | 409 / 329 |
| 日付サンプル数(母集団) | **15(少なすぎて基準値にできない)** | 48 | 78 |
| 日付サンプルの5万再生到達率 | 73%(15本では信頼不可) | 12.5%(中央値848回) | 29.5%(中央値6,336回) |
| ヒットのうちショート / 長尺 | 24 / 277 | 131 / 180 | 89 / 193 |
| 登録者2万人未満のチャンネルのヒット | 76本(65チャンネル) | 64本(23チャンネル) | 117本(106チャンネル) |
| 再生数÷登録者数の中央値 | 4.4 | 5.4 | 13.7 |
| 3本以上ヒットしたチャンネルの割合(再現性) | 8.7% | 27.5% | 4.6% |
| 上位3チャンネルのヒット占有率(競合集中) | 16.5% | 17.9% | 4.2% |
| ヒットのうち日本語 / 他言語 | 115 / 206 | 121 / 531 | **17** / 392 |
| ヒットのうちAI言及タイトル | 42 | 4 | 6 |

注意(重要):
- 日付サンプルが少ない(A=15)ため、Aの「到達率73%」は市場の成功率ではありません。ヒット率は断定しません。
- ジャンルはテーマ検索の割り当てで、動画の中身で分類したものではありません(例: ドラマ系の検索に料理動画も混ざる)。ノイズがあります。
- 登録者数・再生数は取得時点のスナップショットです。YouTube の「AI生成」申告フラグが付いたヒットは0件で、AIで作られた動画と、AIを解説する動画を、今のデータでは区別できません(タイトルのAI言及は参考値)。
- Cの日本語ヒットは17本と少なく、日本語市場の根拠は薄いです(日本語の検索が主に未実行のため)。

### A の日本語ヒットの中身(115本)[実測]
- 長尺(約20分)が108本、ショートは5本のみ。
- 多くが「スカッと系」(理不尽な相手にやり返す実話風の短編を、漫画風の絵とナレーションで見せる形式)。単一の大手チャンネル(登録者71.6万人)が、同じ型で約100万〜250万回のヒットを連発しています。
- 登録者2万人未満のチャンネルのヒットも24本あります。
- この型は、静止画とナレーションで作れるため、既存の制作の流れ(台本・画像・音声・字幕・編集)と相性が良いです。動画生成(Omni)は必須ではありません。

### コスト[公式資料 + 実測]
- Gemini Omni 1.2 Flash: 720pで約$0.07/秒(5,792トークン/秒、動画出力$12/100万トークン)。8秒のクリップ約$0.56、15秒で約$1.04。
- 実測: 8秒の動画1本で動画出力46,336トークン(旧版 omni-1.1: $17.50/100万トークン → 約$0.81)。
- 画像: 8枚で12,425トークン(約1,550トークン/枚)。
- Gemini TTS(3.8 flash): 音声出力$9/100万トークン(2026年末まで。2027-01-01から$18)。10秒あたり約$0.00225。
- 動画生成の1日の上限(Tier 1): 1分8回、1日40回。TTS は1日100回(モデルごと)。

### 選定
オーナー指示のルールに従います。
- 5要素(需要・差別化・制作原価・自動化の容易さ・拡大余地)で、3ジャンルのどれにも**決定的な優位性は確認できませんでした**(データの量が不足)。
- 指示どおり、**A(短編ドラマ・ホラー)を最初の制作候補**にします。映像生成費用は、静止画ナレーション型なら高くないので「継続制作できない」条件には当たりません。
- 最初の形式は**日本語の「スカッと系」長尺(約10〜15分)**。実測で日本語ヒットが最も厚く、既存システムで作れるためです。ストーリーは完全オリジナル(既存作の模倣文は避ける)。
- B(修復)は、再現性27.5%と最も高く、評価を継続します。C(科学)は、日本語の根拠が薄く、保留です。

## 2. チャンネル開設(本人の操作が必要)

### アカウントの選び方
| 方法 | 長所 | 短所 |
|---|---|---|
| 既存の Google アカウントに新規チャンネル | 手早い | 建設事業のアカウントと権限・通知が混ざる。誤操作の影響が大きい |
| 事業専用の新規 Google アカウント(**推奨**) | 完全に分離。API や Cloud の設定も独立 | 電話番号認証が必要 |

### 手順(iPhone または Mac)
1. Mac のブラウザで、新しい Google アカウントを作成(専用のメールアドレス、2段階認証をオン、バックアップコードを保存)。
2. youtube.com にログインして、チャンネルを作成(名前は下の候補から)。
3. YouTube Studio → 設定 → チャンネル → 基本情報で、国を日本に。
4. 設定 → チャンネル → 機能の利用資格で、「電話番号による確認」を行う(15分超の動画やカスタムサムネイルに必要。[未確認]: 現在の条件は公式で確認してください)。
5. 設定 → アップロード動画のデフォルト: 公開設定は「非公開」、「合成コンテンツ」の開示は「はい」にしておく。
6. 完了したら、チャンネル名(@ハンドル)を私に伝えてください。

### チャンネル名の候補(日本語・スカッと系/ミステリー短編)
- 「スカッと夜話」「やり返し劇場」「静かな逆転(仮)」
- どれも仮です。商標・既存チャンネルと重複しないか、作成時に検索して確認してください。

### 説明文(案)
「理不尽な出来事に、静かに、きっちり、やり返す。オリジナルの短編ストーリーを毎週お届けします。この動画は AI を使って制作しています。登場する人物・団体・出来事はすべてフィクションです。」

### アイコン・バナー
- AI 画像で、シンプルな図形と1色のロゴ文字(顔は使わない)。作成は私が行います(承認してから設定)。

## 3. YouTube API・Analytics 連携

既存の API キー(YOUTUBE_API_KEY)は公開情報の読み取り専用です。投稿と自分のチャンネルの分析には **OAuth 2.0** が別に必要です(キーとは別物)。

### 実装状況
`studio/studio/youtube.py`(新規、模擬テストのみ、実サービスでは未実行): 更新トークンでの認証、限定公開でのアップロード、公開は承認が無いと拒否、再生数と Analytics の取得、24時間/72時間/7日/28日の記録。

### 確認できたこと[Web検索。公式の全文は未確認]
- 2026-11-02 の公式の改訂履歴: 未審査プロジェクトからのアップロードが、非公開に強制されなくなった(公開が既定)。コードは、非公開を既定とし、応答の公開状態を記録します。
- インプレッションとクリック率は、新しい名前(`videoThumbnailImpressions`、`videoThumbnailImpressionsClickRate`)の可能性があります。旧名は動画別では400になるとの報告あり。未検証なので、実機で確かめます。
