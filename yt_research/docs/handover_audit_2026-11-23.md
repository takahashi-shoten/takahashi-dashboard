## 2. 市場調査システムの実装状況

### 稼働状況
- **YouTube Data API**: 稼働中です。直近の実行(2026-11-22 19:43 UTC、run #7)は成功しています。
- **実行履歴(yt-research)**: 成功9回、失敗1回です。最終成功は 2026-11-22T19:45 UTC です[実測]。
- **定期実行の実態**: 設定は毎日 08:17 と 12:17 UTC の2回です。実際の自動実行は、11/21 に16:11 UTC の1回、11/22 に16:19 と19:43 UTC の2回で、GitHub 側で大幅に遅延または間引きされています[実測]。24時間の確実な定期実行とは言えません。
- **API 使用量**: 累計17,858ユニット。1日の上限は10,000です。検索は1回100ユニットと重く、1日に約39回までです。

### 収集の内容
- **対象**: 186テーマ。言語・地域別では、日本語(JP)76、英語(US)75、インドネシア18、他は少数です[実測]。
- **実際に検索が実行された**テーマは69件です。日本語24、英語40、その他5です。日本語の検索は、英語に比べて実行が遅れています。
- **ジャンル**: 約40ジャンルです(歴史、ドラマ、資産形成、男性の悩み、性の雑学、科学、ホラーなど)。
- **抽出条件**: 公開から90日以内、再生数50,000以上、音楽(カテゴリID 10)を除外。
- **形式の分類**: 動画の長さなどから、ショート(short_likely)、通常(long)、不明(ambiguous)、配信中(live_or_upcoming)に分けています。
- **偏りへの対策**: 再生順(viewCount)の検索に加えて、日付順の抽出で基準となる母集団を取っています。ヒットの検索だけだと、生き残ったものしか見えないためです。
- **重複排除**: 動画IDで一意にし、再生数は時系列の記録(snapshot)として追加します。

### ファイルサイズ制限の失敗
- **経緯**: DB が約122MB になり、GitHub の上限で push が拒否されました。
- **修正**: 説明文を切り詰めること、gzip 圧縮、履歴を残さない強制 push、サイズの安全装置(90MB 未満)を入れました。
- **現在**: 約28.9MBで、以降の実行は成功しています。
- **再発防止の残り課題**: データは増え続けるので、将来は上限に近づきます。成長ペースは[未確認]です。

### 収集のみのデータと、検証まで終わったデータ

- 保存して集計・分析まで済んでいる: 条件に合う44,920本、チャンネル1,437(監査済み)。仮説は198件あり、判定は「データ不足(insufficient_data)」が多く、結論が出たものは限られます。

## 4. 自律運用の実現度

- **完全自動で動く**: 市場調査の収集・保存・分析・レポート(ただし実行時刻は GitHub の都合で遅延・間引きあり)。
- **自動で動くが人が起動する**: 動画1本の制作。GitHub Actions の `key-check` で `task=produce` を手動実行します。
- **人間が必要**: 公開の判断、YouTube への投稿、チャンネルや各種アカウントの作成、課金、承認。
- **接続待ち**: Gemini 音声の 429 の解消、YouTube の投稿・分析用の連携。
- **エラー時の復旧**: 429 と 5xx には自動リトライ(最大5回)。調査の実行にはガード機能があります。通知機能は**未実装**です。
- **24時間運用**: 現時点ではできません。制作は手動起動です。調査の自動実行も、上記のように時刻が不安定です。
- **1日の制作本数の見込み**: 算出していません(根拠となる大量実行の実測がなく、推測で出さないため)。
