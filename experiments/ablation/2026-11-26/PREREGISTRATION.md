# 事前登録: 保存済み知識19件の有無による成果物の比較(2026-11-26)
この文書は、生成より前にコミットして確定する(後から基準を変えない)。結果は `RESULTS.md`。

## 目的
知識DBに保存した19件が、DBに入っているだけでなく、**成果物の内容を実際に良くするか**を、小さく・安く確かめる。能力の最終証明ではなく**予備評価**(AIによる評価は内部評価で、市場の反応と経済的成果が最終の検証)。

## 条件
- A: 知識を使わない通常のAI。B: 同じ課題・同じ事実・同じルールに、保存済み知識19件(`knowledge.consult` の実コードで作った一覧、状態・確信度・適用条件つき)を加えたAI。それ以外は同一(`prompts/*_A.txt` と `*_B.txt`)。
- 同一モデル(生成: sonnet)、ツール不使用、1課題1回(再試行なし)、字数上限同一、追加費用0円(Claude Code のセッション内サブエージェント。API費用は発生しないが、セッションの利用枠は消費する)。
- B には「知識の使用記録(使ったID・使わなかった理由)」を末尾に書かせる。評価者には見せない(`=====KNOWLEDGE_LOG=====` 以降を削除)。
- 既知の限界: 知識一覧にサロン関連(K14・K15・K18)が含まれ、T1・T2の事実と一部重なる(AとBの事実は同一で、Bだけが知識として持つ)。T3(別業界)・T4(仮想データ)が、より純粋な応用の試験。

## 課題(各課題がカバーする能力)
T1 着付け予約の受け皿整備(集客戦略・販売導線の改善・原因分析)/ T2 実写ショート3本の企画(コンテンツ企画・冒頭の作り方)/ T3 個人事業主向けデジタル商品の企画と販売コピー(**研究に使っていない業界**。顧客心理・商品企画・コピー)/ T4 結果が出なかったときの原因分解と経営判断(**仮想データ**。売れない原因分析・経営判断)。市場調査力は、今回は直接試験しない(別の試験が必要)と明記する。

## 評価(匿名・盲検・順序は乱数で入れ替え)
- 評価者2名(独立。sonnet 1名、opus 1名)。各課題で、出力を X/Y とし、どちらがAかBかを伝えない。割当は固定乱数(seed=20261126)で決め、`blind_map.json` に保存。
- 各出力を、次の8基準で 1〜5 点(1=重大な欠陥 / 3=標準 / 5=優れる)で採点し、全体の優劣(X / Y / 同等)と理由を書く。
  - C1 状況への具体性(与えられた事実を使い、一般論でない)
  - C2 事実の扱い(与えていない数字・事実を作らない、未確認と仮説を区別する)
  - C3 核心課題への的確さ(T1: 導線の断絶と優先順位 / T2: 実写で再現できる型と、検証が分かれた3本 / T3: 顧客の心理障壁の洞察 / T4: 実測と仮説の分離と因果の切り分け)
  - C4 実行可能性(費用0円・人の時間・制約の範囲内)
  - C5 検証可能性(基準値・指標・成功/停止条件が事前に決まっている)
  - C6 訴求・コピー・判断の質(読み手に刺さる具体性。誇大・法令違反なし。T4は判断の筋の通り方)
  - C7 リスク・規約への配慮(景表法・ステマ・誇大・個人情報)
  - C8 非自明性(誰でも書ける一般論ではない)
- 加えて評価者は、(a) 捏造した事実・数字の数、(b) 状況に合わない知識を無理に適用したと見える箇所(あれば)を書く。
- 集計の約束: 点数は課題ごと・評価者ごとに差(B−A)を表示する。**平均点の差が小さい(0.5点未満)ものは「差なし」と読む**。標本は4課題×2評価者で、統計的な有意性は主張しない。

## 判定ルール(事前)
- 課題ごと: 両評価者が同じ側を選べば「その側が優れる」。割れたら「判定不能」。
- 全体: 4課題のうち3課題以上で両評価者がBを選び、かつ C2(事実の扱い)でBが悪化していなければ、「知識の利用は、この条件で成果物を改善した(予備評価)」と書く。それ以外は「改善は示されなかった」と書く。B が優れても、改善が C8(非自明性)や C3 でなく、書き方の丁寧さだけなら、その旨を書く。
- 悪化(Bの方が劣る、知識の誤適用)も同じ重みで報告する。

## 市場での検証(この比較の次)
S1・S2の採用案を、実際に承認を得て実行し、予約数・問い合わせ数・流入元で測る(S1は基準値あり)。T3 は、小さな販売ページ+無料の告知での需要テスト(外部公開と営業にあたる部分は承認が必要)。AIの評価が高いだけでは、知識の確信度を上げない(`tested_internal` までで、`market_validated` は市場の結果のみ)。
