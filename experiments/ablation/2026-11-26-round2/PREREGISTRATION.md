# 事前登録(第2回): 知識の利用方式 A / B / C / D の比較(2026-11-26)
第1回(`../2026-11-26/`)で「知識を企画前に与える(B)」は、成果物を改善しなかった。原因分析は `docs/research/knowledge_ablation_cause_analysis_2026-11-26.md`。この試験は、**利用の方式を変えたとき**に差が出るかを、低費用で見る(予備評価)。
## 方式
- A: 知識なし(第1回の出力を再利用)。A2: Aの再生成1回(生成のばらつきの目安)。B: 企画前に知識19件(第1回の出力を再利用)。
- C: Aの企画を土台に、保存済み知識と照合し、適用条件が合い企画を明確に良くできる箇所だけ修正。D: Aの企画を維持し、知識から作った品質チェックリスト(誇大表現・転載・承認手順・二次情報・導線の断絶・中央値/標本・見出し)で点検し、問題箇所だけ最小修正。
- C・D は A の出力を入力にするため、**処理は2段(Aの生成+修正)**。費用(トークン・時間)は、A+修正として比較する。
- 生成: 新規は A2・C・D の4課題×3=12本(同一モデル sonnet、ツール不使用、各1回)。課題 T1〜T4 は第1回と同じ。
## 評価(盲検・順序の釣り合い・異系統は不可)
- 評価者4名(sonnet 2、opus 2)。各評価者は課題ごとに5つの回答(A, A2, B, C, D)を、課題ごとにランダムな基本順序を、評価者ごとに巡回してずらした順序(4通り)で見る。方式名は伏せ、(C・Dの CHANGES 部分と、Bの知識ID表記は除去)。割当は `blind_map.json`(seed=20261126)。
- 各回答を、第1回と同じ8基準(C1〜C8、1〜5点)で採点し、課題ごとに5つを順位づけ(1=最良)。捏造した事実の数(異なる内容を数える)と理由も書く。
- 異系統(別会社)のAIによる評価は、追加費用なしでは使えないため、今回は行わない(限界として明記)。
## 分析と判定(事前)
- 方式ごとに、評価者4名×課題4の16判断で、平均順位と8基準の平均点を出し、位置ごとの平均順位も出して位置の偏りを確認する。
- 生成のばらつき: A と A2 の平均点・順位の差を、方式間の差の「ノイズの目安」とする。**方式間の差が A−A2 の差より小さければ「差なし」と読む。**
- 「方式Xは有効」の条件: Aに対して、平均順位が良く、かつ平均点の差(X−A)がノイズの目安(|A2−A|)を上回り、かつ評価者4名中3名以上で平均順位がAより良い。いずれも満たさなければ「有効とは示されなかった」。
- 課題の種類ごとに分けて書く(T1 導線の改善 / T2 コンテンツ企画 / T3 商品企画・コピー・顧客心理 / T4 原因分解・判断)。方式の使い分けは、この課題別の結果から提案する(標本が小さいことを併記)。
- 費用: 各エージェントのトークンと所要時間を記録し、方式別に合算する(C・DはA+修正)。
## 限界
標本は4課題×各1回の生成。AI評価(同一会社のモデル)の主観で、市場の反応ではない。C・D は A の出力に依存する(Aが偶然良い/悪いと影響を受ける)。
