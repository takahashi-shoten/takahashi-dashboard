# 評価用の入力(匿名・第2回)
あなたは独立した評価者です。各課題に、同じ課題への5つの回答(P〜T)があります。どう作られたかは分かりません。推測せず内容だけで評価してください。

## 評価基準
- 各出力を、次の8基準で 1〜5 点(1=重大な欠陥 / 3=標準 / 5=優れる)で採点し、全体の優劣(X / Y / 同等)と理由を書く。
  - C1 状況への具体性(与えられた事実を使い、一般論でない)
  - C2 事実の扱い(与えていない数字・事実を作らない、未確認と仮説を区別する)
  - C3 核心課題への的確さ(T1: 導線の断絶と優先順位 / T2: 実写で再現できる型と、検証が分かれた3本 / T3: 顧客の心理障壁の洞察 / T4: 実測と仮説の分離と因果の切り分け)
  - C4 実行可能性(費用0円・人の時間・制約の範囲内)
  - C5 検証可能性(基準値・指標・成功/停止条件が事前に決まっている)
  - C6 訴求・コピー・判断の質(読み手に刺さる具体性。誇大・法令違反なし。T4は判断の筋の通り方)
  - C7 リスク・規約への配慮(景表法・ステマ・誇大・個人情報)
  - C8 非自明性(誰でも書ける一般論ではない)
- 加えて評価者は、(a) 捏造した事実・数字の数、(b) 状況に合わない知識を無理に適用したと見える箇所(あれば)を書く。
- 集計の約束: 点数は課題ごと・評価者ごとに差(B−A)を表示する。**平均点の差が小さい(0.5点未満)ものは「差なし」と読む**。標本は4課題×2評価者で、統計的な有意性は主張しない。



## 追加: 順位
課題ごとに、5つを最良から最悪の順(1位〜5位)に並べてください(同順位なし)。
