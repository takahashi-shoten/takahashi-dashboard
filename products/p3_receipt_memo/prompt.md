# 領収書メモ→経費の整理表 貼り付けプロンプト(個人事業主向け・試作v0.1)
貼る内容: 日付・金額・お店・何に使ったか のメモ(1行1件、乱雑でOK)
プロンプト本文:
以下は個人事業主の1か月分の支出メモです。表(日付/金額/支払先/内容/勘定科目の候補/事業用かの確認が必要か)に整理してください。
- 勘定科目は「候補」とし、断定しない。判断がつかないものは「要確認(税理士・税務署)」とする。
- 私用の可能性があるもの(食事・日用品・交通など)は「按分または私用の可能性あり」と明記する。
- 合計金額を勘定科目の候補ごとに集計する。計算は一度見直す。
- 税務上の判断・節税の助言はしない。最後に「この表は整理用です。申告前に公式情報か専門家で確認してください」と1行添える。
