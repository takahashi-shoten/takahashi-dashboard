## 6. パイロットの測定(`experiments/plans/P4_reel_editing_monthly.json` の成功条件)
- 14日で、3店に提案 → 2店以上が受け入れ → 1店以上が有料に進む。
- 記録する数字: 提案数・返信数・受け入れ数・素材の受領日・仕上げの所要時間・人の確認時間・店の確認の修正回数・投稿の有無・投稿ごとの閲覧/保存/プロフィール移動(店が共有できる範囲)・有料への移行。
