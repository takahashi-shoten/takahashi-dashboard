## 2. 対象店の条件(仮説。選び方の根拠は未検証)
- Instagramを既に持ち、投稿が止まっている/少ない着付け・サロン・ネイル等の小規模店。撮影は手元中心で済む。
- 面識があり、結果を正直に共有してくれる関係。**身内(奥さんの店)は数えない**。
- 最初は3店。10店に提案して反応0なら中止(`P4_reel_editing_monthly.json`)。

## 3. パイロット条件(案)
- 無料: 実写クリップ受領 → 1〜2本を仕上げ(縦1080x1920・テロップ・予約案内・カバー・投稿文)→ 店が自分で投稿。
- 約束すること: 納期(受領後3営業日以内[仮])、修正1回、2週間の数字の共有。
- **約束しないこと**: 予約・売上の増加、フォロワー増。成果の保証・誇大表現は禁止。
- 相手にお願い: 掲載(匿名)許可、数字(リーチ・保存・プロフィールアクセス)のスクショ、感想。撮影に写る人の同意は店側で。
- AI利用の明示: 編集・テロップ・文案にAIを使う。AI生成の映像は使わず、**実写素材のみ**。
