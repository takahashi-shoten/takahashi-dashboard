## 次の作業(上から順に、承認不要の範囲で実行する。実行したら、結果を書いて判定を更新)
1. **データ取得の可否を確認**(各ホストが、サンドボックスから到達できるか。到達できなければ、Actionsで実行): 公開データセット・公式API(例: Steam、Kickstarter公開データ、Amazonレビュー公開データセット、各アプリストアの公開ランキング、Google Trends、各国の統計・調査機関の公開資料)。利用規約・ライセンスを記録し、使えるものから大量に取り込む。
2. **C-01の差別化の検証**: 無料の代替との比較(実際に試す)と、高単価の専門分野の需要の証拠。
3. **未調査の分野(教育・趣味・物理商品・SaaS・海外各地)の購買需要の一次データ**を取り、AI実現可能性を、工程分解して判定。
4. 『顧客の不満』の収集(レビュー・SNS・掲示板の公開データ)→ 未充足需要の候補化 → 新規ビジネスの考案(異業種の成功モデルとの組み合わせ)。
5. 有望な候補は、`OPPORTUNITY_HANDOFF.md` に書いて親に渡す。
