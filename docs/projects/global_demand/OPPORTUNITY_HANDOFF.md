# 親へ渡す商機(本プロジェクト → 親の商業実験)
根拠が十分な候補だけを、次の形式で書く。親は、これを読んで実験を準備する(外部公開・出品・営業・課金は、オーナーの承認が先)。結果は親が `CANDIDATES.md` の「実験結果」に返す。
```
## H-001 候補名(日付)
- 対象顧客 / 購買需要の証拠(URL・日付・数値・信頼度) / 具体的な商品仕様 / 競合との差別化 / 販売価格 / 制作・提供原価(実測 or 推定) / 利益構造 / 利用技術(検証結果へのリンク) / 集客方法 / 販売先 / 実験方法(最小・安価・速い) / 成功・失敗の判定条件(事前登録) / 人の作業時間 / 承認が必要なこと
```
(まだ、渡せる商機はない。最初の候補は、`CANDIDATES.md` の検証後に、ここに書く)
