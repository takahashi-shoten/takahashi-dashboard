# セッション開始・終了の手順(恒久ルール。全セッション・全エージェントに適用)

根拠: オーナー指示(2026-11-26「過去の全作業・知識・成果の完全継承と永続的な活用」)。チャットが変わるたびに知識・判断・成果が失われてはならない。同じ調査・開発・説明の繰り返し、解決済みの問題の再検討、オーナーへの同じ説明の要求は禁止。

## 開始時(毎回。全チャットの読み直しではなく、索引から必要な原資料へ)
1. `CLAUDE.md` と `docs/MANAGEMENT_PRINCIPLES.md` を読む(最新の有効な方針)。
2. `docs/PROJECT_STATE.md`(現在地・索引・次の仕事)と `docs/DECISIONS.md`(有効な指示と変更の経緯)を読む。
3. ブランチを確認する: `git fetch` して `main` / `claude/funny-allen-4qkj7d` / 自分の作業ブランチ / 最新コミットを比べ、未統合の成果がないか見る。マージはオーナーの承認が必要。
4. 前回の終了時点を確認する: `PROJECT_STATE.md` の「未完了」と、直近の `docs/SESSION_LOG.md` の末尾。
4b. Actionsで記録された知識使用を取り込む: `git fetch origin studio-data && git show origin/studio-data:knowledge_uses.jsonl > /tmp/ku.jsonl && (cd studio && python -m studio.knowledge import-uses ../knowledge/marketing_knowledge.db /tmp/ku.jsonl)`(重複は入らない)。
5. これからやる仕事に関連する過去の知識・成果を引く(**関連する知識は `knowledge.relevant(...)` で選ぶ。『関連なし』も有効な結果**): 知識DBは `knowledge.for_task(con, task, context, used_in=…)`(使用が記録される)。実験は `experiments/plans/`、分析は `docs/research/`。
6. 重複確認: 同じ調査・開発・検証が既にないかを、索引と `git log --oneline` で確認してから着手する。再検証が必要なら、過去の検証で何が不足していたかを先に書く。
7. 予算と承認範囲を確認する(`CLAUDE.md` の予算決定。研究・学習API費 2,000円、残りは未承認)。
8. 最も収益化に寄与する仕事を選び、理由を記録して、承認済み範囲で着手する。

## 作業中
- **変更・施策を提案する前に、対象(チャネル・市場・商品)の実態を先に調べ、根拠(出典・区分)を付ける(オーナー指示 11-26)。** 想像・n=1の観察だけで文言や施策を作らない。調べていない範囲は、提案の前に明記する。
- 既存資産を再利用する。作り直さない。変更前にバックアップ(`studio.snapshot export`)。
- 保存済みの分析結果があるのに、APIで再取得しない。不足が確認できたときだけ、承認済み予算内で追加分析する。
- 知識を使ったら、どの知識を・なぜ・どう応用し・結果がどうだったかを記録する(`knowledge_uses`、実験カードの `knowledge_used`)。未検証の仮説を確定ノウハウとして扱わない。
- 重要な成果は、途中でも、その場でファイルに保存してコミット・pushする(突然終了しても失われないように)。
- 機密情報(キー、トークン、個人情報、店舗が特定できる情報)は公開リポジトリに保存しない。
- 外部公開・新規契約・予算増額・秘密情報・破壊的変更・PRマージは、承認が記録されるまで実行しない。

## 終了時(または区切りごとに必ず)
`docs/SESSION_LOG.md` の末尾に1節追記し、`docs/PROJECT_STATE.md` と `docs/DECISIONS.md` を更新して、コミット・pushする。
追記する項目: 実施した作業と結果 / 新しく得た知識(知識DBへの追加) / 成功・失敗と根拠 / 問題と解決 / 実際の費用と所要時間 / オーナーの新しい指示・承認 / 更新したファイル・コミット / 未完了 / 次回の具体的な作業。

## 検証
引き継ぎの仕組みは、「作った」では完了としない。会話を与えない別エージェントが、保存された情報だけから、目的・方針・成果・失敗・知識・使い方・予算と承認・次の仕事を正しく答えられるかを、原資料と照合する(結果は `docs/SESSION_LOG.md` に記録)。
